# ⚡ Catalyst 2026 - CISSA Hackathon

A rapid Python + Streamlit web application built for the CISSA Catalyst 2026 Hackathon.

---

## 🚀 Quick Setup for Teammates

Follow these 4 simple terminal commands to run the project locally on your machine:

### 1. Clone the repository & enter the folder
```bash
git clone https://github.com/montyabbas07-code/Catalyst2026.git
cd Catalyst2026
```

### 2. Create and activate a Python virtual environment
**On macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**On Windows (Command Prompt / PowerShell):**
```cmd
python -m venv venv
venv\Scripts\activate
```

### 3. Install the dependencies
```bash
pip install -r requirements.txt
```

### 4. (Optional) Set up your Gemini API Key
```bash
cp .env.example .env
```
Open `.env` and paste your Google Gemini API key if needed.

### 5. Run the web app!
```bash
streamlit run app.py
```
Your browser will open automatically at `http://localhost:8501`.
